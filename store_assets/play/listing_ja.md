- **詳細な説明 (4000文字以内)**:
『フォントスタイラー』は、Web/アプリデザイナー、フロントエンドエンジニア、UI/UXクリエイターのための完全オンデバイス・タイポグラフィ検証＆コードスニペット生成ツールです。

モバイル画面上でフォントサイズ（px/rem）、ウェイト（100〜900）、行間（line-height）、字間（letter-spacing）、テキスト配置や変形を直感的なスライダーで微調整し、美しい文字組のプレビューと各種フレームワーク向け実装コードをワンタップで取得できます。

---

### ■ 主な機能と特徴

1. **直感スライダーによるタイポグラフィ精密チューニング**
   - **フォントサイズ**: 12px〜72px（pxとremをリアルタイム相互換算）
   - **フォントウェイト**: 100 (Thin) 〜 900 (Black) の9段階精密ウェイト
   - **行間 (Line Height)**: 1.0x〜2.5xの滑らかな倍率調整
   - **字間 (Letter Spacing / Tracking)**: -0.05em〜+0.30emのトラッキング
   - **フォントファミリー**: Sans-Serif (ゴシック), Serif (明朝), Monospace (等幅), Cursive (筆記体)
   - **配置・変形・装飾**: 左/中央/右揃え、UPPERCASE、斜体、下線

2. **マルチプラットフォーム・コード即時生成 (ワンタップコピー)**
   調整したスタイルを以下の主要フォーマットに即座に変換：
   - **CSS**: `.typography { font-size: 24px; font-weight: 700; line-height: 1.5; ... }`
   - **Tailwind CSS**: `text-2xl font-bold leading-normal tracking-wide text-slate-100`
   - **Jetpack Compose**: `TextStyle(fontSize = 24.sp, fontWeight = FontWeight.Bold, ...)`
   - **Flutter**: `TextStyle(fontSize: 24.0, fontWeight: FontWeight.w700, height: 1.5, ...)`
   - **SwiftUI**: `.font(.system(size: 24, weight: .bold)).lineSpacing(...)`

3. **WCAG 2.1 コントラスト比・アクセシビリティ判定**
   - 文字色と背景色のコントラスト比をW3C計算式に基づき即時算出
   - AA / AAA / Large AA の適合判定をバッジで分かりやすく可視化
   - 誰もが読みやすいデザインシステムやWebサイト構築をサポート

4. **厳選20選！デザイナーズ・タイポグラフィプリセット**
   - 目的別にプロが調律した即戦力スタイルを収録：
     - **Headings**: Hero Display (巨大見出し), Modern H1, Section H2, Subtitle H3
     - **Body & Reading**: Clean Body (黄金比本文), Lead Paragraph, Compact Caption, Blockquote
     - **UI Components**: Button CTA, Navigation Tab, Badge Pill, Stat Big Number
     - **Editorial & Serif**: Luxury Serif, Literary Essay, Vintage Headline
     - **Tech & Monospace**: Code Snippet, Terminal Prompt, Data Table, Cyberpunk Neon

5. **マイタイポグラフィ保存 ＆ 共有**
   - 作成したお気に入りの文字組設定をローカルDataStoreに名前をつけて無制限保存
   - ワンタップでエディタに再読み込み可能

6. **安心の完全ローカル動作・プライバシー最優先**
   - 外部サーバーへの通信は一切不要
   - アカウント登録不要、完全オフラインで快適に動作
