# App Information (Google Play Console Listing)

## Basic Information
- **App Name**: FontStyler - Typography Inspector & Code
- **Short Description (max 80 chars)**:
Tune typography on device: font size, weight, line height & export CSS/Tailwind code
- **Full Description (max 4000 chars)**:
FontStyler is the ultimate mobile typography workbench and code snippet generator designed for UI/UX designers, frontend developers, and mobile engineers.

Fine-tune font size (px & rem), font weight (100–900), line-height, letter-spacing (tracking), text transforms, and alignments directly on your device. Export production-ready code with a single tap.

---

### ■ Key Features

1. **Precision Typography Controls**
   - **Font Size**: 12px to 72px with live px-to-rem conversions.
   - **Font Weight**: 9 granular steps (100 Thin to 900 Black).
   - **Line Height (Leading)**: Smooth multiplier from 1.0x to 2.5x with exact pixel rendering.
   - **Letter Spacing (Tracking)**: -0.05em to +0.30em tracking adjustments.
   - **Font Families**: Sans-Serif, Serif, Monospace, and Cursive.
   - **Alignment & Transform**: Left/Center/Right, UPPERCASE, Italic, and Underline.

2. **Instant Multi-Platform Code Export**
   Convert your typography configuration into clean code with one tap:
   - **CSS**: `.typography { font-size: 24px; font-weight: 700; ... }`
   - **Tailwind CSS**: `text-2xl font-bold leading-normal tracking-wide text-slate-100`
   - **Jetpack Compose**: `TextStyle(fontSize = 24.sp, fontWeight = FontWeight.Bold, ...)`
   - **Flutter**: `TextStyle(fontSize: 24.0, fontWeight: FontWeight.w700, ...)`
   - **SwiftUI**: `.font(.system(size: 24, weight: .bold)).lineSpacing(...)`

3. **WCAG 2.1 Contrast Ratio Inspector**
   - Real-time accessibility calculation against text and background colors using official W3C formulas.
   - Clear compliance badges for WCAG Level AA, AAA, and Large Text standards.

4. **Curated 20 Designer Typography Presets**
   - Ready-to-use typography recipes across 5 categories:
     - **Headings**: Hero Display (64px), Modern H1, Section H2, Subtitle H3
     - **Body & Reading**: Clean Body (Golden ratio), Lead Paragraph, Compact Caption, Blockquote
     - **UI Components**: Button CTA, Navigation Tab, Badge Pill, Stat Big Number
     - **Editorial & Serif**: Luxury Serif, Literary Essay, Vintage Headline
     - **Tech & Monospace**: Code Snippet, Terminal Prompt, Data Table, Cyberpunk Neon

5. **Saved Custom Styles**
   - Save custom typography schemes locally with custom names.
   - One-tap reload into the live inspector anytime.

6. **100% Offline & Privacy-First**
   - Zero network requests required.
   - No login, no tracking, complete peace of mind. Works perfectly in airplane mode.
