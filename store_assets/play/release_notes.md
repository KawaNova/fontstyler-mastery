# リリースノート (Release Notes)

## Version 1.0.0 (1) - 2026-10-17

### 日本語 (ja-JP)
- 『フォントスタイラー - タイポグラフィ検証＆コード生成』初回リリース！
- 直感スライダーによるフォントサイズ（px/rem）、ウェイト（100〜900）、行間、字間の精密調整
- マルチプラットフォーム・コード即時生成（CSS, Tailwind CSS, Jetpack Compose, Flutter, SwiftUI）
- WCAG 2.1 コントラスト比・アクセシビリティ自動判定（AA / AAA / Large AA）
- 厳選20選！デザイナーズ・タイポグラフィプリセット収録（Headings, Body, UI, Editorial, Tech）
- マイタイポグラフィのローカル保存機能
- 完全オフライン動作＆プライバシー保護設計

### English (en-US)
- Initial release of FontStyler - Typography Inspector & Code!
- Precision typography tuning: Font size (px/rem), weight (100–900), line height, and tracking.
- Instant code snippet export for CSS, Tailwind CSS, Jetpack Compose, Flutter, and SwiftUI.
- Real-time WCAG 2.1 contrast ratio evaluation (AA / AAA compliance).
- 20 curated designer typography presets across 5 categories.
- Custom typography saving with local offline storage.
- 100% offline functionality and privacy-first architecture.
